- 逻辑沟通是什么
    - 传达信息
        - 有效传达
            - 缩短时间
                - “眼里只有自己”
                - “瞬间读心术综合征”
        - 传达什么
            - 信息三条件
                - 主题简明
                - 期待对方的反应
                - 一个明确的答案
            - 时刻回归：主题、期待的反应
            - 期待
                - 理解
                - 反馈判断、意见
                - 采取行动
            - 答案三要素
                - 结论
                - 论据
                - 方法
                    - 具体做法
            - 结论陷阱
                - 结论成“归纳答案”，而不是“归纳自己想说的”
                - “根据情况”、“有些场合”导致各说各话
            - 论据陷阱
                - “因为缺乏A，所以需要A”
                - 对方产生疑虑“这是事实、还是你自己的判断”
                - 只有传达方认为“理所当然”
            - 方法陷阱
                - 其他公司公理、很久前的公理，无法调动员工
                - 修饰语无法替代观点
    - 为什么回答没有说服力
        - “答案”重复、遗漏、离题
            - 重复是“大脑混乱”的标志
            - 遗漏导致“一着不慎，满盘皆输“
        - “答案”不连贯
- 逻辑思维
    - 消除答案的重复、遗漏、离题
        - [[MECE]]
        - 分组
            - 目的：制定不遗漏、不重复、不离题的子集
    - 消除答案的不连贯
        - So What，从材料提炼
        - Why So，追问
        - So What/Why So 的两种类型
            - 观察型，用于说明现象
            - 洞察型，用现象提炼
- 建构逻辑
    - 使用So What/Why So
        - 逻辑是，根据纵、横两项法则，将结论、论据、方法串联进来的结构
        - 纵向法则 So What/Why So
        - 横向法则 MECE
        - 纵向几层，整体情况到2层，阐述到3层
        - 横向几层，4、5个以内
    - 逻辑模式
        - 并列型
            - 一个结论，再多方法并列
            - 论据并列
            - 方法并列
            - 恰当的MECE切入点
        - 解说型
            - 一个结论，再说事实、判断标准、判断内容
            - 解说论据
            - 解说方法
            - 注意事项
                - 正确的“事实”
                - 明确判断标准，确保内容恰当
                - “事实、判断标准、判断内容”流程，前后含义一致性
    - 运用和逻辑模式
