- __显示图片__
- display *.png       # 幻灯片
- delay 5            # 5百分之秒切换
- 快捷键
    - 空格            # 下一张
    - 退格            # 上一张
    - h               # 水平翻转
    - v               # 垂直翻转
    - /               # 顺时针翻转90度
    - \               # 逆时针旋转90度
    - `>               # 放大`
    - &lt;               # 缩小    - f7              # 模糊
