- 方法参数都是值传递，无法改变外部的参数本身
- 可变参数(1.5)
    - public void sum(int x, int... args)
- static方法初始化先于构造方法
- overload与override
    - 重载
        - 父类、同类、子类中比较
        - 方法名一致，入参有变化
        - 返回值不影响
            - 为副作用调用时(忽略返回值)考虑
        - 修饰符、异常声明不影响
    - 重写
        - 入参，出参一致
        - 构造方法、final方法不能被重写
        - static方法不能被重写，可再次声明
        - 访问权限不能缩小
        - 异常声明不扩大，可加非强制异常
- finally
    - return前走finally, catch块中也一样
