- 第一曲线
    - 相当于遗传，连续性创新
    - 3个特征
        - 沿着技术曲线持续改善原有的产品性能
        - 定位于主流市场的主流消费者
        - 更好
    - 为什么有极限点，人效降低
        - 熵：不能转化成功的能量的度量
            - 在自然过程中， 一个孤立（封闭）系统的总混乱度（即“熵”）不会减小
                - 代表了在封闭系统中，如果熵增加，封闭系统的总能量不变时，其中可用能量将减少
                - 熵增不可逆，越来越多的有效能量将转为无效能量
    - “对一个公司的CEO来说，识别极限点的能力价值千金” — 福斯特
        - 单一要素10倍速变坏，是企业即将到达极限点的信号
            - 单一要素指标为”隐曲线“，财务指标为”显曲线“
                - “隐曲线”等于“显曲线”到达极限点
    - 企业的宿命
    - 传统管理会扼杀创新
- 第二曲线
    - 相当于新物种，非连续性创新
    - “市场增长速度超过个体企业增长速度的原因，在于市场基于非连续性的破坏性思维，企业则基于连续性的保护性思维“ — 福斯特
    - 通过“创造性破坏”，跨越到第二曲线上
        - “第二曲线创新”是经济发展的唯一因素“ — 熊彼特
    - “母系统”破坏“子系统”
        - “整个生物界就是这样，细胞的更替成就了个体的延续，个体的死亡成就了种群的延续，种群的灭亡成就了自然的延续”
        - “并不是基业长青的大公司拉动了经济增长，而是对过气大公司的破坏推动了经济增长” — 福斯特
    - 企业“长寿”方法论
        - 守正出奇
            - 管理：尽量延长第一曲线的“生命”
            - 创新：启动独立的第二曲线
        - 回避雷区
            - 生硬转型
                - “终其天年而不中道夭” — 庄子
            - 新旧合并
        - 开启第二曲线的时机
            - 第一曲线已过“破局点”
            - 不晚于财务“极限点”
                - 第一曲线增速已经放缓，或加速度开始下降时，就应该开始了
- 分形创新
    - 与进化论同构性
        - 变异 + 选择 = 新物种
        - 创新 + 选择 = 第二曲线
    - 分形创新
        - 第二曲线是从第一曲线的分形创新中生长而来的
    - 变异的数量与速度
        - 变异的数量：同行借鉴
        - 变异的速度
            - 分形算法
                - $$z = z^2 + c$$
                - 验证性学习
                    - 最小化可行性产品MVP（Minimu Viable Product）
                - 过程就是目的
                    - 乔布斯，“他走的每一步都是上一步的必然结果”
