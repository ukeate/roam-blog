- 实现
    - 层
        - User Interface
        - Application Services
        - Domain Services
        - Domain Model
    - 对象
        - 视图对象
            - Vo
        - 数据传输对象
            - DTO
        - 数据存储对象
            - Po(Persistent Object)、Do(Data Object)
        - 领域对象
            - Do(Domain Object)、Bo(Business Object)、无后缀
    - 严格分层，不隔层调用
- 优点
    - 各层职责清晰，提高大型复杂项目的可维护性
    - 结合DDD，使项目以领域模型为主
    - 没有外部依赖，方便单元测试
- 缺点
    - 简单系统会加大复杂性
    - 对技术人员要求高
